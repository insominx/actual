## Account owner findings

Current `api/account-create` delegates to `accounts/app.ts#createAccount`. That owner creates the account and its transfer payee. A nonzero opening balance also calls `accounts/payees.ts#getStartingBalancePayee` and creates a cleared opening transaction dated with `monthUtils.currentDay()`. The helper can create a missing Starting Balance payee. A preview must inspect those references without calling that writing helper. Bind the execution date or reject a date change before applying, so the promised opening date matches the canonical writer. Acknowledgement must report actual generated identities; matching names cannot prove an uncertain creation.

Current `closeAccount` calls `unlinkAccount` before checking existence/closed state, ledger balance and transfer destination. Unlink clears local bank/provider fields and can remove a last GoCardless bank requisition remotely. Guarded close/delete must validate account, provider state, balance, transfer account/payee and category references before invoking this owner. Preview must disclose unlink consequences. A zero-transaction closure deletes the account; forced deletion also deletes source transactions, clears reciprocal transfer references and deletes the transfer payee. Merely fingerprinting the account row would miss required dependencies.

Account creation is now implemented and verified locally on Windows; close/delete remain owner findings, not implemented adapters or personal-budget actions. Keep the existing writer and external unlink authority. Do not patch preview with a rollback, call a writing helper from inspection, or infer global atomicity from the local mutator.

## Hold owner findings

It changes buffered only when to-budget is positive, then uses calcBufferedAmount to cap the requested increase to available funds. Reset calls setBuffer(month, 0), creating a missing row as needed. Guarded previews must use these existing calculation and writer owners, bind the relevant row/mode and engine input, and report the actual clamped result.
