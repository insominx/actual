# Execution decisions

- D7 (design wall, 2026-10-03): invalid budget identities were retried as transient worker failures. Preserve redacted engine error codes across the private worker pipe and stop on permanent context/encryption failures. A valid Actual sync ID remains required; cloud-file IDs do not become a new public selector. The failed invalid-ID probe timed out before this fix, then returned a nonretryable context error. Confidence: high. Additive private worker result; no API identity change. Relationship: aligned. Review: pending independent review.

## Watch and failure decisions — 2026-10-03

- D4 (design wall): the public API does not expose cancellation for all initialization and binary sync requests. Watch uses a disposable process running the same public API connection, with bounded attempt duration. Credentials cross a stdin pipe; progress diagnostics omit secrets. The alternative unbounded in-process await would prevent timely cancellation. Worker deadlines and active-request stdin cancellation passed real stalled-server probes. Confidence: high. Operational process isolation is additive; no ledger owner moved. Relationship: extends lifecycle implementation while preserving API authority. Review: pending independent review.
- D5 (design wall): a failed post-write push retained an observed freshness label and recent cache checkpoint. Invalidate that checkpoint and mark freshness unknown while retaining committed-local. A fault proxy rejects requests containing message envelopes. Plaintext and encrypted tests prove one retained account creation, positive pending counts, and one independent remote account after refresh. The prior freshness assertion failed before this fix. Confidence: high. Cache-only metadata change; no mutation replay. Relationship: aligned. Review: pending independent review.
- D6 (tradeoff): watch returns one bounded version 2 document after completion, with progress events on stderr. Default sample count is 100; callers can set 1-1000. The alternative unbounded JSON stream conflicts with the current one-result contract. Bounded polling and reconnect use capped exponential backoff. Confidence: high. Additive CLI command; streaming output could be a later separately versioned contract. Relationship: aligned. Review: pending independent review.
