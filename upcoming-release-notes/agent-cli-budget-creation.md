Add local budget creation, inspection, saved selection, and isolated cloning through the CLI and public API. The CLI can create a budget and optional currency preference without a browser or remote publication. Clones receive separate local and synchronization identities and never publish automatically.

Add explicit publication, identity-preserving rename, and reversible device-local archiving. Supported servers can register an encryption key during the first encrypted upload. Publication retains one file identity and recovers accepted uploads after a lost response.
