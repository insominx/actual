## Executive summary

- Fan-out "review → verify → fix" worked well: 3 waves of Opus reviewers led to 113 verified bug fixes in 2 commits. Every suite ended green: core 1575, web 1335, sync-server 672, CLI 417, api 143.
- The costliest waste came from the environment, not from logic:
  - A rate limit killed 8 subagents mid-run.
  - A repo-wide `yarn lint:fix` rewrote about 650 unrelated files.
  - A persistent `cd` broke 7 commands in a row.
  - `npx vitest --root packages/desktop-client` failed 3 separate times.
- The CRLF snapshot churn from the 2026-10-19 retro came back about 5 more times. That meets the revisit condition recorded in that retro's no-change decision.

## Recommendations

1. **Document the working desktop-client test command.**
   - Evidence: E05
   - Expected gain: no more `--root` failures by agents
   - Artifact target: `AGENTS.md`, Testing Strategy
   - Token/context impact: about 2 lines of standing context
   - Owner/reviewer: repo owner
   - Rollback or review condition: remove if `vite.config.mts` stops resolving paths against cwd
2. **Scope formatting to changed files on Windows / autocrlf checkouts.**
   - Evidence: E03, E04
   - Expected gain: no repo-wide churn, and no keep-list reverts
   - Artifact target: `AGENTS.md`, Lint/test/typecheck section
   - Token/context impact: about 3 lines
   - Owner/reviewer: repo owner
   - Rollback or review condition: remove once line endings are normalized (recommendation 3)
3. **Fix the line-ending root cause.**
   - Evidence: E04 (7 times over 2 days), E03
   - Expected gain: no more phantom diffs
   - Artifact target: `.gitattributes` (`*.snap text eol=lf`), or local `git config core.autocrlf false` followed by `git add --renormalize .`
   - Token/context impact: none
   - Owner/reviewer: repo owner. This changes git behavior, so it is a human decision.
   - Rollback or review condition: revert if other contributors see new churn
4. **Save the Bash-cwd lesson as a personal memory.**
   - Evidence: E02
   - Expected gain: fewer failed command bursts
   - Artifact target: user memory (feedback)
   - Token/context impact: one index line
   - Owner/reviewer: user
   - Rollback or review condition: drop if the harness stops persisting cwd
